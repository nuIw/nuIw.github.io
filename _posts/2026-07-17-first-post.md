## 블로그를 시작한 이유

인공지능 논문과 연구 내용을 체계적으로 기록하기 위해 GitHub 기술 블로그를 시작했습니다.

공부하거나 연구하면서 이해한 내용을 단순히 보관하는 데 그치지 않고, 다른 사람이 읽어도 흐름을 이해할 수 있는 형태로 정리하는 것이 목표입니다.

## 주요 관심 분야

현재 주로 공부하고 있는 분야는 다음과 같습니다.

- Video-Language Model
- Visual Token Compression
- Query-aware Token Pruning
- Object Tracking and Trajectory Modeling
- Parameter-Efficient Fine-Tuning
- Low-Rank Adaptation

## 블로그에서 기록할 내용

앞으로 다음과 같은 내용을 정리할 예정입니다.

### 논문 리뷰

논문의 내용을 다음 구조를 중심으로 분석합니다.

- Motivation
- Method
- Experiments
- Conclusion
- Limitation
- 현재 연구와의 연결점

### 연구 기록

연구를 진행하면서 발생하는 다음 내용을 기록합니다.

- 문제 정의
- 연구 아이디어
- 방법론 설계
- 실험 결과
- 실패한 접근
- 후속 실험 방향

### 개발 기록

구현 과정에서 발생한 환경 설정과 오류 해결 과정도 함께 기록합니다.

- Python 및 PyTorch 환경 설정
- Git과 GitHub 사용법
- 모델 학습과 평가
- 오류 원인과 해결 방법

## 앞으로의 목표

논문을 단순히 요약하는 것을 넘어, 논문이 어떤 문제에서 출발했고 어떤 가정을 통해 해결책을 설계했는지 분석하려고 합니다.

또한 연구 과정에서 얻은 실험 결과와 의문점을 지속적으로 기록하여, 연구 방향이 어떻게 변화했는지 추적할 수 있는 블로그를 만들 계획입니다.
